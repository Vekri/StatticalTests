# Statistical Tests Lab (Streamlit)

Load sample CSV templates (or upload your own) and run all 6 tests:

1. Z-Test  
2. t-Test  
3. Chi-Square  
4. ANOVA  
5. Correlation & Regression  
6. A/B Test  

## Run

From the project root:

```bash
pip install -r requirements.txt
streamlit run streamlit_app/app.py
```

## Sample CSV templates
